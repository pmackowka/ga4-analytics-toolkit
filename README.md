# web-analytics

Przykłady kodu i realnych analiz z pracy jako Data Analyst / Analytics Architect w e-commerce: automatyzacje wokół GA4/GTM, pobieranie danych przez API do BigQuery, audyty implementacji analitycznych i rozwiązania zadań analitycznych.

## Zawartość

| Folder | Co zawiera |
|---|---|
| [`ga4-api/`](ga4-api) | GA4 Data API w Pythonie — tutorial, gotowe raporty CLI, Cloud Function importująca dane Ads do BigQuery codziennie |
| [`google-ad-manager/`](google-ad-manager) | Raporty przez Ad Manager API (delivery, inventory, reach) |
| [`gtm-implementation/`](gtm-implementation) | Custom JS z realnych wdrożeń Google Tag Managera |
| [`audits/`](audits) | Audyt konfiguracji GA4/GTM dla realnego wdrożenia (centrumrespo.pl) |
| [`case-studies/`](case-studies) | Rozwiązanie zadania rekrutacyjnego: modelowanie danych i analiza w BigQuery/SQL |
| [`notes/`](notes) | Notatki z nauki nowych narzędzi (MCP) |

## Stack

Python, SQL (BigQuery), GA4 Data API, Google Ads/Ad Manager API, Google Tag Manager, Google Cloud Functions.
